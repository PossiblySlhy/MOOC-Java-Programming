
MOOC Java Programming - University of Helsinki
=============================================

Project: MOOC-Java-Programming
Owner: Blake Phillips
Branch: main

Description
-----------
This repository contains my solutions and exercises from the University of Helsinki
Java Programming MOOC. The exercises are organized as small Java projects used
for learning and practicing the language and basic algorithms.

Notes
-----
- Many of the main Java functions or classes in this repository may intentionally
	be left empty or minimal. This is because the submissions and tests are run
	against the University of Helsinki's automated testing server. Some exercise
	templates are kept in a stubbed form to allow their code to be validated
	externally.
- Use the University exercise runner or the provided test scripts (if any) to
	verify solutions.

Structure
---------
- Each exercise typically has its own folder with source files.
- Follow the course material for where and how to implement solutions.

Contributing / Usage
---------------------
- This is a personal learning repository. You can browse the solutions, but be
	aware they may be incomplete on purpose.
- To run or test an exercise locally, import the project into your Java IDE or
	run the provided build/test commands if available.
